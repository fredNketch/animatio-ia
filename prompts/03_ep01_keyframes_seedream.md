# Épisode 1 — Keyframes (images de départ) · Seedream 4.5

> Pour chaque scène, on génère d'abord **l'image de la première frame** dans Seedream, en combinant les références (perso + décor). Cette image devient la **première frame** de la vidéo Seedance. C'est ce qui garantit que chaque scène démarre exactement dans le bon décor, avec les bons personnages.

**Réglages :** format **9:16**, résolution **2K**, 4 variantes → garder la meilleure.
**Nomenclature :** `production/keyframes/EP01_S0X_KF_v<N>.png`

**Pourquoi des keyframes ?** Le rôle "first frame" fixe la composition exacte ; les références perso dans Seedance verrouillent l'identité pendant le mouvement. Combiner les deux = le maximum de contrôle.
